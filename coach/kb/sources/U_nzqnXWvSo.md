## Claims
- Daily 1% gains compound to roughly 37x in a year; 1% daily decline compounds toward zero. [00:01]
- Small daily choices are already reshaping you; people overvalue dramatic transformation. [00:01]
- Habits run through four stages: noticing, wanting, doing, liking. [00:32]
- People usually lack clarity, not motivation; fix it by stating when, where and how the habit happens. [00:32]
- A failure pre-mortem (imagine failing in six months, narrate why) exposes obstacles to plan around. [01:33]
- Add if-then backup plans, e.g. a named fallback slot if the planned session is missed. [01:33]
- Your physical environment drives desire; make good behaviors easier and bad ones harder. [02:03]
- Consistent positive habits rarely survive a hostile environment; willpower only wins occasionally. [02:33]
- Early on, just put in reps; any outcome is a point on a spectrum of repetitions. [03:04]
- Optimize for the starting line (ease of starting), not the finish-line milestone. [03:34]
- Good habits cost now and pay later, so bring a reward into the present via short-term feedback. [04:06]
- Wall-calendar X chain: mark each day done; the goal becomes not breaking the chain, regardless of quality. [05:07]
- Each action is a vote for an identity; you need a majority of votes, not perfection. [06:38]
- Aim to become a type of person (a runner), not to hit a one-off goal. [07:08]
## Protocol candidates
- Prompt the user to set each habit as when / where / how before the day starts. [01:03]
- Ask a pre-mortem question when creating a habit, then require an if-then backup slot. [01:33]
- Place the cue object in sight (book on pillow, guitar in the room). [02:33]
- Show a visible chain/X per completed day. [05:07]
- Frame completions as identity votes ("you showed up as a runner"). [06:38]
## Game-design notes
- Chain-tracking as instant reward: marking the day is the in-the-moment payoff. [05:07]
